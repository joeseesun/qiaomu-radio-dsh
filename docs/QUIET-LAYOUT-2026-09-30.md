# 安静反馈与插件内沉浸布局

## 行为

- 切换皮肤仅保存外观，保留当前电台、队列、播放状态与屏内页面，不再停止音频、清空电台或重新请求目录。
- 删除切换皮肤、收藏、不喜欢的成功通知；错误与目录回退仍有反馈，通知脱离布局流。
- 页面在窄容器也铺满插件区域。极简、Winamp、foobar2000 扩展内容与列表；iPod 保持比例，两款 3D 场景使用可用空间。
- 无系统全屏按钮和 Fullscreen API，保留 Harness 侧栏与窗口。

## 自检证据

- `npm run check`：12 个测试文件、111 项测试通过；typecheck 与生产构建通过。
- 新增媒体回归：开始播放后切换皮肤，不调用 media.pause/load，不新增 resolvePlay/catalog 请求，当前电台仍在，未出现通知条。
- `npm run preview`：Chrome 实际渲染检查六款皮肤在浅色、深色（1440×900）、窄屏（640×900）的18个组合；背景铺满，机身与主要控件可见。
- 实际 DeepSeek Harness 打开已安装的乔木电台：魔兽模型正常显示，背景铺满内容区，左侧 Harness 导航保留。
- 真实网络音频连续性本轮未独立听音验收；不中断逻辑由注入媒体回归覆盖。
