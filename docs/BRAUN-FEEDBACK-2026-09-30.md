# 博朗菜单反馈调整

- 菜单行增加 4px 投影等效间距与圆角，保持至少 44px 点击高度。
- hover 使用中性半透明浅底；当前行使用深绿底；键盘 focus-visible 使用暖色内描边，不改变布局。
- 实体菜单方向键同步 DOM 焦点与选中行，避免双重高亮以及 Enter 激活旧行。

验证：npm run check 全绿（13 个测试文件，113 项）；加入两种实体皮肤方向键焦点同步回归断言。npm run preview 实看当前安装四款皮肤浅色、深色、640px 窄容器；博朗菜单行保持间距，方向键焦点跟随。DSH 使用指向主工作区的现有安装链接，生产构建更新 lib/player。
