# 实体屏内导航

博朗与魔兽点击屏幕后，HTML 菜单通过 CSS3D 投影到机身显示屏，镜头平滑对准屏框。移除原来的大型外置面板与重复播放控件。导航复用频道、地区、搜索、喜欢和历史页面。

关闭或 Escape 返回收听并恢复进入菜单前的机位；返回按钮逐级导航；选中电台回到 now 时自动退出。搜索页重置滚动并聚焦输入框。菜单打开不重建音频或场景。博朗拆解保留为独立图标。

文字与交互区域按聚焦后的投影尺寸补偿：主要菜单行/关闭/返回约44px，常规文字18px。减少动效时直接到目标机位。

## 验证

- `npm run check`：13 个测试文件、113 项测试通过；类型检查、生产构建通过。
- 新增两款实体皮肤的真实控制器+场景桩回归：点击屏幕打开菜单，选台后关闭，搜索框 Escape 关闭，浏览不暂停媒体、不销毁场景。
- `npm run preview` 真浏览器：博朗点击进入、频道/返回/搜索、输入 Escape 退出；魔兽 Enter 打开、关闭回到画布。
- 五皮肤浅色、深色1440×900与窄屏640×900实测；两款实体菜单均在屏框内显示。
- 真实网络音频连续性本轮未单独听音验收；不中断由控制器/媒体回归覆盖。宿主重新打开电台后加载新构建。
