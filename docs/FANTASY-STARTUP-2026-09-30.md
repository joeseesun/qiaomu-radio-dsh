# 魔兽 3D 启动优化

模型及三张 WebP 贴图都在随包 GLB 内，2,744,956 字节，无远端纹理依赖。
本机 HTTP 读取实测约 2 ms；不能把整个 loading 时间当成下载时间。

## 变更

- 使用 three.js 自带 Octree 为静态模型建立临时空间索引，屏幕和按钮投射只检查相关三角面。
- 保留双面材质的射线语义、原坐标、网格密度、相机及模型资产；不降低模型精度。
- 索引仅在校准阶段使用，后续按钮/扬声器变形继续使用现有模型。
- 超过 15 秒未就绪时使用原有 CSS 回退，并释放场景；成功、失败及卸载均清理定时器，忽略迟到回调。
- 修正 preview 未复制模型和图片、仍使用旧路由前缀的问题，预览现在真实加载随包 3D 模型。

## 验证

- `npm run check`：12 个测试文件、110 项测试通过，typecheck/build 成功。
- 真实模型 97,300 个三角面；对照所有屏幕/按钮投射顶点，误差 < 1e-6。
- 本机 Node 几何基准：原屏幕 514 ms + 按钮 3051 ms；索引构建 1054 ms + 屏幕 4 ms + 按钮 6 ms，总计约 1064 ms，减少约 70%。这是计算基准，不是端到端首帧时间。
- `npm run preview`：Chrome 实际检查 fantasy/rams/editorial/pocket/deck/console，1440×900 浅色、dsw-dark 深色、640×900 窄容器，均可见完整播放器；两款 3D 模型正常渲染。
- DeepSeek Harness 实际点击「乔木电台」，dsh-app://app/qiaomu-radio/ 的魔兽模型成功呈现，loading 消失。安装包通过 profile link 使用当前 lib 构建。
- 定时器测试覆盖挂起超时、成功取消超时、失败释放和迟到回调。

此前阅读插件导入失败的启动日志属于另外的宿主启动故障，本改动不声称修复其根因。
